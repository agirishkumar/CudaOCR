# Kernel benchmarks — custom CUDA kernels vs NVIDIA NPP (`_Ctx` APIs)

Generated by `./build/bench` (20-iteration average, 2500×3500 8-bit image) on an RTX 3060
Laptop (sm_86), CUDA 13.4, driver 595.99 — 2026-11-02.

| Kernel | Custom ms | NPP ms | Custom / NPP | |
|---|---:|---:|---:|---|
| grayscale (BT.601) | 0.137 | 0.112 | 1.22× | within the 2× target |
| box mean 31×31 | 2.440 | 19.502 | 0.13× | **8× faster** — separable running sums vs NPP's direct window |
| Gaussian 5×5 | 0.758 | 0.293 | 2.59× | global-memory taps; shared-memory tiles planned (BACKLOG M6.2) |
| median 5×5 | 19.234 | 0.719 | 26.8× | per-thread insertion sort; sorting network planned (M6.1) |

In the pipeline these kernels are a small share of page time: on a dense 300 dpi page the
whole GPU preprocessing + deskew + line detection takes ≈ 3 ms (median 3×3 ≈ 0.2 ms), while
recognition takes ≈ 370 ms (`cudaocr --benchmark`).
